## Assets que precisam ajuste/correção

- assets/personagens/animais.svg — Verificar necessidade de separar todos os animais individualmente e revisar proporções (alguns animais podem estar fora do padrão de "cabeça grande" ou sem sorriso/amigável).
- assets/personagens/jesus.svg — Rechecar se segue todos os requisitos do guia visual: tom de pele moreno, olhos castanhos, manto azul, dignidade (não estereotipado e nem simplificado demais).
- assets/personagens/discipulos.svg — Reforçar diversidade (tonalidades de pele, idades, gêneros), revisar vestimenta para evitar repetição de cores.
- assets/personagens/criancas.svg — Conferir se mostra diversidade (meninas, meninos, tons de pele, diferentes tipos físicos).
- assets/personagens/familia-noe.svg — Verificar se inclui todas as pessoas-chave e variedade de tons de pele/cabelos.
- assets/cenarios/interior-arca.svg — Revisar distribuição de elementos; verificar clareza das zonas/compartimentos para ativ. de jogos.

## Assets possivelmente faltantes

- Ícones de itens para atividade de organização (ex: alimentos, ferramentas bíblicas, bandagens, pães, peixes: sugerido usar carta emoji ou criar SVGs no mesmo estilo)
- Mais expressões para personagens principais (alegre, pensativo, triste), especialmente para feedbacks do jogo
- Possíveis cenas urbanas ou domésticas de época (cenários alternativos para histórias)

## Notas gerais
- Alguns assets podem precisar de pequenos ajustes para convergir totalmente no estilo flat amigável do guia visual.
- Recomenda-se, ao criar ou revisar, garantir viewBox e tamanhos conforme padrão do projeto.

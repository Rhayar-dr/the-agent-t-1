# LearningJesus

Criar um workflow de geração de vídeos educativos para crianças sobre a bíblia e os ensinamentos de Jesus, criação também de storytelling educativo e criação de jogos interativos que ensinam sobre a palavra na bíblia e como tratar bem as pessoas e organização.

Projeto desenvolvido pela equipe de agentes de IA do escritório **The Agents**.
